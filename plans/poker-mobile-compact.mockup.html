Design Changes Summary

1. Team Votes: Cards → Pills

  • Replaced large 2-column cards with inline pills that wrap naturally
  • Each pill: status icon + name + optional host star
  • ~120px total height vs ~240px+ before (for 5 participants)
  • Voted = green, waiting = grey, revealed = indigo with vote value
  • Current user highlighted with indigo ring (same as before)
  • Outliers get red styling when votes are spread

2. Voting Cards: 4-col → 5-col grid

  • All 10 cards in a 5×2 grid instead of 4-col with overflow rows
  • Slightly smaller cards but still very tappable (min 56px wide)
  • Keeps the familiar card shape (3:4 aspect ratio)
  • Reduced padding around the card container

3. Queue: Sidebar → Collapsed toggle

  • On mobile, queue collapses to a single-line progress bar
  • Shows "Queue · 2 of 6" with a mini progress bar
  • Tap to expand/collapse the full queue list
  • Saves ~200px of vertical space when collapsed

4. Reveal Button: Always visible

  • Full-width button that's always above the fold
  • No scrolling needed to reach it

5. General spacing tightened

  • Margins between sections: 12px (was 24px)
  • Card container padding: 12px (was 16-24px)
  • Item title: 17px (was 20px / text-xl)
  • "End Session" moved to header as a compact button

6. Desktop unchanged

  • All changes are behind mobile breakpoints (below lg:)
  • Desktop retains sidebar queue, larger cards, card-style team votes
