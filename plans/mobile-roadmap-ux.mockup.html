Key Design Decisions

1. Vertical Stacking

Instead of a horizontal timeline, periods stack vertically. This matches mobile's natural scroll direction and gives each period full screen width.

2. Position = Bar Width

An item's position within a period is shown by its bar width and offset. Full width = entire period. Half width at right = second half of period.

3. Overflow Indicators

Items spanning multiple periods show arrows (→ ←) to indicate continuation. The item appears in each period section it spans.

4. Touch-Friendly Editing

Tap to select, then drag handles to resize. No complex gestures needed. Moving is achieved by shrinking one side and extending the other.

Implementation Summary

Vertical Stacked Timeline for Mobile

This design transforms the horizontal desktop roadmap into a mobile-friendly vertical layout while preserving full editing capability. The key insight is that position within a period can be represented by bar width and offset rather than requiring horizontal space.

Full Editing Support

Users can resize items by tapping to select and dragging handles. Moving is achieved by adjusting both edges.

Period Management

Add periods at bottom, tap headers to rename or delete. Same capabilities as desktop.

Add Items

Unscheduled items shown at bottom. Tap one to select period. FAB adds new items (consistent with other views).

Visual Continuity

Items spanning periods show overflow indicators. Users can scroll to see the full extent.

No features removed: Everything possible on desktop is possible on mobile, just with touch-optimised interactions.
