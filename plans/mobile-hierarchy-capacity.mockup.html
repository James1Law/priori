Capacity view — mobile design decisions

Colour accent bar on the left — same level colours as backlog list. Gives immediate visual grouping without eating horizontal space.

Title always on its own line — no truncation. Wraps naturally.

Estimate right-aligned — compact input for leaves, rolled-up total for parents. Smaller input (w-10) on mobile.

Rank badges removed on mobile — position in list is obvious, and the number adds noise.

Status shown inline with level badge — saves a whole column.

Tap to open drawer — entire row is tappable (except estimate input). Uses active:bg-gray-50 for touch feedback.

Reduced indent — same 0.75rem/level, capped at 2.25rem.
