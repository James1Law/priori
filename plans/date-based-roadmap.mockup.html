Scenario 3

Zoom Presets & View Controls

Users can zoom in/out of the timeline using presets or manually set the date range. "Fit" auto-expands to show all scheduled items with padding.

Fit Auto-fit to all items
Default mode. Calculates the min start date and max end date across all scheduled items, adds 1 week padding each side. If no items have dates, shows today → today + 1 month.
3M 3-month window
Shows today – 2 weeks through today + 2.5 months. Week-level granularity. Good for sprint-level planning.
6M 6-month window
Shows today – 1 month through today + 5 months. Week-level granularity with month labels prominent.
1Y 1-year window
Shows today – 1 month through today + 11 months. Month-level granularity (no week subdivisions). Good for strategic planning.
Custom Manual date range
User sets explicit start and end dates via the date inputs. Switching to any preset deselects Custom. Editing a date input auto-switches to Custom mode.
Scenario 4

Drag Interactions

Drag bars to move or resize. Hierarchy constraints enforced in real-time. Dates update on drop.

🔄 Move (grab bar)
Shifts start_date and end_date by the same delta. Duration preserved. Children move proportionally with parent.
↔️ Resize (drag edge)
Drag left edge = change start_date. Drag right edge = change end_date. Min 1 day duration. Children constrain parent (can't shrink past children).
📏 Hierarchy Rules
Children can't exceed parent bounds. Parents can't shrink past children. Moving a parent moves all descendants by same day offset.
Design Notes

Data Model & Migration

New Database Fields

  • items.start_date — date, nullable. When null = unscheduled.
  • items.end_date — date, nullable. When null = unscheduled.
  • sessions.roadmap_zoom — text, default 'fit'. One of: 3m, 6m, 1y, fit, custom.
  • sessions.roadmap_start_date — date, nullable. Used when zoom is custom.
  • sessions.roadmap_end_date — date, nullable. Used when zoom is custom.

Deprecated (can remove later)

  • items.roadmap_start_quadrant, items.roadmap_end_quadrant, items.roadmap_row
  • items.roadmap_start_period, items.roadmap_end_period
  • roadmap_periods table

Hierarchy Constraints (same logic, new data type)

  • canResizeChild() — child's dates must be within all ancestor date bounds
  • canResizeParent() — parent's dates must contain all descendant date spans
  • getProportionalMoves() — when parent moves N days, all descendants shift N days

Pixel Mapping

  • Given view start date S, end date E, and container width W:
  • pixelsPerDay = W / (E - S in days)
  • barLeft = (item.start_date - S) * pixelsPerDay
  • barWidth = (item.end_date - item.start_date + 1) * pixelsPerDay
  • On drag, reverse: newDate = S + (mouseX / pixelsPerDay)

Empty State

  • No items with dates: show today → today + 1 month, with message "Set dates on items to see them on the roadmap"
  • Items without dates appear in the unscheduled panel below the timeline
