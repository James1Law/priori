Benefits of This Approach

More Screen Space

Sidebar is collapsed by default, giving items list full width. The 30% add form only appears when needed.

Mobile Parity

Users can now add items with descriptions on mobile via the modal. FAB is consistent across all views.

Framework Context

Framework selector only appears in relevant views (Scoring). Other views show current framework as a badge.

Alternative: Inline Quick Add

Instead of slide-in panel, expand inline below the tabs.

Proposal Summary

1.
Desktop: Move framework selector to tab bar. Add "Add Item" button that expands slide-in panel or inline form. Sidebar is collapsed by default.
2.
Mobile: Add FAB (floating action button) that opens bottom sheet modal for adding items. Framework selector moves to menu (kebab icon).
3.
Framework visibility: Show framework selector only in Scoring view. In other views, show current framework as a read-only badge.
4.
Consistency: FAB appears on all mobile views (Scoring, Estimates, Backlog, Roadmap placeholder) so users can always add items.
