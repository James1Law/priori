Design notes:
  • Bottom tab bar matches production: 3 pill buttons (List/Roadmap/Capacity), active = indigo
  • 5 hierarchy levels shown: Goal → Initiative → Epic → Story → Subtask
  • Each level gets progressively indented (28px per level) with a coloured left border
  • Level badges use distinct colours: Goal (pink), Initiative (blue), Epic (purple), Story (amber), Subtask (red)
  • Standalone items (no children) have no level badge — identical to current production
  • Cutoff lines only apply between top-level items
  • Rank numbers only on top-level items
  • Parents show progress bar + "X/Y done" instead of status badge
  • "+ Add [child type]" buttons below each expanded parent's children
