Data Model Changes

CURRENT Period-based

items.roadmap_start_period
items.roadmap_end_period
// FK to roadmap_periods

NEW Quadrant-based

items.roadmap_start_quadrant
items.roadmap_end_quadrant
// Integer: absolute quadrant index
// Period 1 = quads 0-3
// Period 2 = quads 4-7, etc.
Migration Note: We can convert existing period-based data to quadrant-based. Each item currently at period N (start) to period M (end) becomes quadrant N*4 to (M+1)*4-1 (full periods).

Proposed Additional Enhancements

🎯 Snap-to-Grid Option

Toggle between free positioning and snap-to-quadrant mode for precise alignment.

📊 Row Management

Allow items on the same row (swimlanes) for overlapping timelines when there's no conflict.

🏷️ Visual Indicators

Show dotted quadrant lines on hover during drag to help with precise positioning.

⌨️ Keyboard Support

Arrow keys to nudge items by one quadrant for fine-tuning without mouse.
