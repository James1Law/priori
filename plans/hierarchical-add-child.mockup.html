Inline add flow:
  • The + Add [level name] button appears below the last child of each expanded parent
  • Button text includes the parent name for clarity: + Add story to "Welcome Flow Redesign"
  • Clicking opens an inline input at the same indentation level as the children
  • Level badge shown in the input to confirm what type of item will be created
  • Enter saves and keeps the form open for rapid entry (add another)
  • Shift+Enter saves and closes the form
  • Esc cancels and closes the form
  • After saving, the new item appears in the list with default "To Do" status
  • Button also appears for items with no children yet (on hover/focus) to start the hierarchy

Toolbar dropdown behaviour:
  • No selection: Main button creates a top-level item. Dropdown shows all ancestor options.
  • Item selected: Main button changes to "Add [child level] to [selected item name]". One click to add a child.
  • Dropdown caret: Opens menu showing available options: add top-level, add as child of any ancestor in the current context.
  • The dropdown intelligently shows only valid options based on the current selection and max depth (level 4).

Drag-to-reparent rules:
  • Drag an item towards the right while hovering over a potential parent → reparent mode activates
  • Target item shows blue highlight and "Drop to add as child" message with the level it will become
  • The dragged item (and any of its children) auto-adjust their item_level relative to the new parent
  • Max depth validation: If reparenting would push any descendant beyond level 4, the drop zone shows red and says "Cannot add — exceeds max depth"
  • To undo: drag the child item back out to the root level, or use the parent selector in the item drawer
  • Items that become children of a parent automatically get a level badge assigned

First child flow:
  • Any item can become a parent by adding a sub-item to it
  • The item's level stays at whatever it currently is (level 0 if standalone)
  • The child is created at parent.item_level + 1
  • A level badge appears on the parent once it has children
  • The parent gains an expand/collapse toggle
  • If the user cancels (Esc without entering text), the item reverts to its original appearance
